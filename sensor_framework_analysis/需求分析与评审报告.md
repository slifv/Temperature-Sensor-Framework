## 1. 项目背景与目标

### 1.1 背景

在嵌入式IoT产品开发中，传感器数据采集是核心功能之一。不同MCU平台（STM32、ESP32、nRF52、GD32等）在硬件抽象、驱动模型、RTOS支持等方面存在显著差异，导致传感器相关代码难以复用和维护。

### 1.2 目标

设计并实现一套**跨MCU平台的Sensor框架**，具备以下核心能力：

| 目标 | 描述 |
|------|------|
| **平台无关** | 核心逻辑与硬件平台解耦，通过适配层支持多MCU |
| **可扩展** | 新增传感器类型只需实现标准接口，无需修改框架 |
| **灵活滤波** | 支持多种滤波算法，可动态组合与切换 |
| **应用解耦** | 数据消费端（GUI/MQTT/业务逻辑）通过发布-订阅模式获取数据 |
| **类型安全** | 利用C++模板与接口抽象，编译期保证类型安全 |

| **FR-EH-05** | 支持异常计数器与熔断机制：连续异常超过阈值时停止采样并上报，防止系统资源被耗尽 | P1 |
| **FR-EH-06** | 支持心跳监测：每个传感器定时上报"存活"状态，超时未上报则标记为离线 | P1 |
| **FR-EH-07** | 支持异常日志记录：时间戳、传感器ID、异常类型、异常值、处理动作，存储于环形缓冲区 | P1 |
| **FR-EH-08** | 异常事件通过EventBus分发给订阅者（GUI告警显示、MQTT异常上报、业务逻辑安全联动） | P1 |
| **FR-EH-09** | 支持滤波器异常保护：滤波输出值NaN/Inf检测、滤波发散检测（连续多步输出变化率异常增大） | P2 |
| **FR-EH-10** | 支持异常恢复后的自动恢复机制：通信恢复→自动重启采样，数据恢复正常→清除降级标记 | P2 |

| **FR-MC-02** | 每种滤波器可独立裁剪：未使用的滤波算法不参与编译，对应的代码和数据缓冲区零占用 | P0 |

## 6. 滤波算法设计

### 6.1 支持的滤波算法

#### 6.1.1 滑动均值滤波 (Moving Average Filter)

| 属性 | 说明 |
|------|------|
| **原理** | 对窗口内N个采样值取算术平均 |
| **窗口大小** | 可配置（典型值: 4/8/16/32） |
| **适用场景** | 抑制周期性噪声，信号平滑 |
| **计算复杂度** | O(1)（维护累积和） |
| **延迟** | (N-1)/2 个采样周期 |

```
公式: y[n] = (x[n] + x[n-1] + ... + x[n-N+1]) / N
```

#### 6.1.2 中值滤波 (Median Filter)

| 属性 | 说明 |
|------|------|
| **原理** | 对窗口内N个采样值取中位数 |
| **窗口大小** | 可配置（典型值: 3/5/7） |
| **适用场景** | 抑制偶发性脉冲噪声/毛刺 |
| **计算复杂度** | O(N log N) 或 O(N)（使用选择算法） |
| **优点** | 对孤立异常值抑制效果极好 |

#### 6.1.3 一阶低通滤波 (First-Order Low-Pass Filter)

| 属性 | 说明 |
|------|------|
| **原理** | 当前输出 = 当前输入×α + 上次输出×(1-α) |
| **截止频率** | 由系数α决定，α越小平滑效果越强 |
| **适用场景** | 温度等慢变化信号的实时平滑 |
| **计算复杂度** | O(1) |
| **内存占用** | 仅需保存上一次输出值 |

```
公式: y[n] = α·x[n] + (1-α)·y[n-1]
其中: α = Δt / (RC + Δt)，0 < α ≤ 1
```

#### 6.1.4 卡尔曼滤波 (Kalman Filter)

| 属性 | 说明 |
|------|------|
| **原理** | 基于状态空间模型的最优递归估计 |
| **模型** | 一维（温度值）状态估计 |
| **参数** | 过程噪声Q、测量噪声R |
| **适用场景** | 已知系统动态模型，高斯噪声环境 |
| **计算复杂度** | O(1)（一维卡尔曼） |
| **优点** | 自适应性强，兼具平滑与跟踪能力 |

```
预测步骤: x̂⁻[n] = x̂[n-1],   P⁻[n] = P[n-1] + Q
更新步骤: K[n] = P⁻[n] / (P⁻[n] + R)
         x̂[n] = x̂⁻[n] + K[n]·(z[n] - x̂⁻[n])
         P[n] = (1 - K[n])·P⁻[n]
```

#### 6.1.5 加权移动平均 (Weighted Moving Average)

| 属性 | 说明 |
|------|------|
| **原理** | 近期的数据权重更大，较远的数据权重更小 |
| **适用场景** | 需要同时考虑平滑性和响应速度 |

```
公式: y[n] = Σ(w[i]·x[n-i]) / Σw[i],  for i=0..N-1
```

#### 6.1.7 通用滑动窗口滤波框架 (Sliding Window Filter Framework)

| 属性 | 说明 |
|------|------|
| **原理** | 维护固定大小N的环形缓冲区，新数据自动覆盖最旧数据；提供`apply()`虚方法供子类实现具体窗口算子 |
| **窗口大小** | 可配置（典型值: 4/8/16/32），运行时也可调整（触发reset） |
| **适用场景** | 作为均值滤波、中值滤波、截尾均值滤波等窗口类滤波器的统一基类，避免重复实现环形缓冲区逻辑 |
| **计算复杂度** | O(1)（数据插入）；算子复杂度取决于子类实现 |
| **内存占用** | N × sizeof(float) + 元数据（约40字节），满足NFR-21 |

**设计动机**：将"滑动窗口数据管理"与"窗口算子逻辑"分离。均值滤波、中值滤波、截尾均值滤波都依赖环形缓冲区——抽象为统一基类后，新增窗口类滤波器只需实现算子，无需重写缓冲区逻辑。

```
架构:
┌─────────────────────────────────────────────┐
│         SlidingWindowFilter (抽象基类)        │
│  ┌─────────────────────────────────────┐    │
│  │  RingBuffer (float buffer[N])       │    │
│  │  push(value) → 自动覆盖最旧数据       │    │
│  │  getWindow() → const float* + size   │    │
│  │  isReady() → 窗口是否填满             │    │
│  └─────────────────────────────────────┘    │
│                                             │
│  virtual float apply() = 0;  ← 子类实现     │
│                                             │
│  float update(value) {                      │
│      buffer_.push(value);                   │
│      if (!buffer_.isReady()) return value;  │
│      return apply();  // 委托子类算子        │
│  }                                          │
└────────────────────┬────────────────────────┘
                     │ 继承
         ┌───────────┼───────────┬──────────────┐
         ▼           ▼           ▼              ▼
   ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
   │ 均值滤波  │ │ 中值滤波  │ │截尾均值  │ │ 自定义..  │
   │ apply(){ │ │ apply(){ │ │ apply(){ │ │ apply(){ │
   │  return  │ │  return  │ │  排序→   │ │  ...     │
   │  mean(); │ │ median();│ │  trim→   │ │          │
   │ }        │ │ }        │ │  mean(); │ │          │
   └──────────┘ └──────────┘ └──────────┘ └──────────┘
```

```cpp
// ─── sliding_window.hpp ────────────────────────────────
#pragma once
#include "feature_config.hpp"
#include "filter_interface.hpp"
#include <algorithm>
#include <cstring>

#if SENSOR_FEATURE_FILTER_SLIDING_WINDOW

template <size_t N>
class SlidingWindowFilter : public IFilter {
    static_assert(N >= 3, "Window size must be >= 3");
public:
    SlidingWindowFilter() { reset(); }

    // 插入数据并返回窗口算子结果
    float update(float input) override final {
        buffer_[writeIdx_ % N] = input;
        writeIdx_++;
        if (writeIdx_ < N) {
            return input;  // 窗口未填满时透传原始值
        }
        return apply();    // 委托子类窗口算子
    }

    void reset() override {
        writeIdx_ = 0;
        std::memset(buffer_, 0, sizeof(buffer_));
    }

    // 获取窗口数据（供子类算子使用）
    const float* getWindow() const { return buffer_; }
    size_t getWindowSize() const { return N; }
    bool isReady() const { return writeIdx_ >= N; }

protected:
    // ★ 纯虚方法：子类实现具体的窗口算子
    virtual float apply() = 0;

    // 获取窗口数据的可写副本（供排序类算子使用）
    void getSortedCopy(float* out) const {
        std::memcpy(out, buffer_, N * sizeof(float));
        std::sort(out, out + N);
    }

private:
    float   buffer_[N];
    size_t  writeIdx_;
};

#endif // SENSOR_FEATURE_FILTER_SLIDING_WINDOW
```

**基于滑动窗口重构已有滤波器**：

```cpp
// 均值滤波：复用滑动窗口基类，仅实现算子
template <size_t N>
class MeanFilter : public SlidingWindowFilter<N> {
    const char* getName() const override { return "Mean"; }
    bool setParameter(const char* key, float value) override { return false; }
    float getParameter(const char* key) const override { return 0.0f; }

protected:
    float apply() override {
        float sum = 0.0f;
        for (size_t i = 0; i < N; i++) {
            sum += this->getWindow()[i];
        }
        return sum / N;
    }
};

// 中值滤波：复用滑动窗口基类
template <size_t N>
class MedianFilter : public SlidingWindowFilter<N> {
    const char* getName() const override { return "Median"; }
    bool setParameter(const char* key, float value) override { return false; }
    float getParameter(const char* key) const override { return 0.0f; }

protected:
    float apply() override {
        float sorted[N];
        this->getSortedCopy(sorted);
        if (N % 2 == 1) {
            return sorted[N / 2];
        } else {
            return (sorted[N / 2 - 1] + sorted[N / 2]) / 2.0f;
        }
    }
};
```

#### 6.1.8 截尾均值滤波 — Olympic Average (Trimmed Mean Filter)

| 属性 | 说明 |
|------|------|
| **原理** | 取滑动窗口内m个值，排序后去掉最小的n个和最大的n个，剩余(m-2n)个值取算术平均 |
| **别名** | 奥林匹克平均(Olympic Average)、截尾均值(Trimmed Mean)、Modified Mean |
| **窗口大小m** | 可配置（典型值: 5/7/9），运行时配置 |
| **截尾数n** | 可配置（典型值: 1或2），需满足 m > 2n ≥ 0 |
| **适用场景** | 存在偶发性异常值但又不希望完全丢弃多个样本；比中值滤波保留更多分布信息，比均值滤波更抗干扰。典型应用：体育评分(去掉最高最低分)、温度测量中抗瞬态干扰 |
| **计算复杂度** | O(m log m)（排序），或 O(m)（使用nth_element部分排序优化） |
| **内存占用** | ≤ m × 4B × 2（buffer + sorted copy）+ 元数据 |

```
算法步骤（m=7, n=2 为例）:

窗口原始值: [25.1, 24.8, 99.9, 25.0, 25.3, 0.1, 25.2]
                 │          异常高      异常低       │
    排序后:   [0.1, 24.8, 25.0, 25.1, 25.2, 25.3, 99.9]
              └──┬──┘                           └──┬──┘
           去掉min 2个                         去掉max 2个
    保留:                       [25.0, 25.1, 25.2]
    结果:                       mean = 25.1
```

```cpp
// ─── trimmed_mean_filter.hpp ──────────────────────────
#pragma once
#include "feature_config.hpp"
#include "sliding_window.hpp"

#if SENSOR_FEATURE_FILTER_TRIMMED_MEAN

template <size_t M, size_t N_Trim>
class TrimmedMeanFilter : public SlidingWindowFilter<M> {
    static_assert(M > 2 * N_Trim, "M must be greater than 2*N_Trim");
    static_assert(N_Trim >= 1, "N_Trim must be >= 1");

public:
    const char* getName() const override {
        return "TrimmedMean";
    }

    bool setParameter(const char* key, float value) override {
        // 运行时支持微调trim比例（但窗口大小编译时固定）
        if (std::strcmp(key, "trim") == 0) {
            size_t newTrim = static_cast<size_t>(value);
            if (newTrim >= 1 && M > 2 * newTrim) {
                runtimeTrim_ = newTrim;
                return true;
            }
        }
        return false;
    }

    float getParameter(const char* key) const override {
        if (std::strcmp(key, "trim") == 0) return runtimeTrim_;
        if (std::strcmp(key, "window") == 0) return M;
        if (std::strcmp(key, "effective") == 0) return M - 2 * runtimeTrim_;
        return 0.0f;
    }

protected:
    float apply() override {
        size_t trim = runtimeTrim_;
        float sorted[M];

        // 获取排序副本
        this->getSortedCopy(sorted);

        // 计算截尾后的均值
        float sum = 0.0f;
        size_t count = M - 2 * trim;
        for (size_t i = trim; i < M - trim; i++) {
            sum += sorted[i];
        }
        return sum / static_cast<float>(count);
    }

private:
    size_t runtimeTrim_ = N_Trim;  // 运行时可调整（不超过编译期约束）
};

// ─── 便捷别名 ──────────────────────────────────────────
// 7选5均值（去掉1个最大+1个最小，体育评分标准）
template <size_t M = 7>
using OlympicFilter = TrimmedMeanFilter<M, 1>;

// 7选3均值（去掉2个最大+2个最小，更激进去噪）
template <size_t M = 7>
using HeavyTrimmedFilter = TrimmedMeanFilter<M, 2>;

#endif // SENSOR_FEATURE_FILTER_TRIMMED_MEAN
```

**性能优化：部分排序**

当 m 较大而 n 较小时，全排序 O(m log m) 可优化为 O(m) 的部分排序：

```cpp
// 优化版：使用 std::nth_element 替代全排序
float applyOptimized() {
    float buffer[M];
    std::memcpy(buffer, this->getWindow(), M * sizeof(float));

    size_t trim = runtimeTrim_;

    // 第1步：将最小的trim个元素移到前部
    std::nth_element(buffer, buffer + trim, buffer + M);
    // 第2步：在剩余部分将最大的trim个元素移到后部
    std::nth_element(buffer + trim, buffer + M - trim, buffer + M);
    // 此时 buffer[trim .. M-trim) 即为保留区间（未排序，但值已正确）

    // 第3步：计算中间部分的均值
    float sum = 0.0f;
    for (size_t i = trim; i < M - trim; i++) {
        sum += buffer[i];
    }
    return sum / static_cast<float>(M - 2 * trim);
}
```

| **DS18B20** | OneWire | ±0.5°C | -55~125°C | 单总线、可寄生供电、可级联 | 多点测温 |
| **SHT30** | I2C | ±0.3°C | -40~125°C | 高精度、已校准、体积小 | 环境监测 |
| **TMP117** | I2C | ±0.1°C | -55~150°C | 医疗级精度、16bit ADC | 高精度场景 |
| **NTC热敏电阻** | ADC | ±1°C | -40~105°C | 成本极低、无数字接口 | 低成本产品 |
| **MCU内置温度** | 内部ADC | ±2°C | -40~85°C | 零成本、无需外部元件 | 芯片温度监控 |

### 10.2 温度传感器实现示例

```cpp
// ─── SHT30 温度传感器实现 ──────────────────────────
class SHT30Sensor : public SensorBase<TemperatureData> {
public:
    SHT30Sensor(uint32_t id, II2CBus& i2c, uint8_t addr = 0x44)
        : i2c_(i2c), addr_(addr), sensorId_(id) {}

    bool init() override {
        // 1. 检测设备是否存在
        // 2. 发送软件复位命令
        // 3. 配置测量模式（单次/周期）
        // 4. 初始化滤波器管道
        return true;
    }

    TemperatureData readRaw() override {
        // 1. 发送测量命令 (0x2C06: 高精度模式)
        uint8_t cmd[] = {0x2C, 0x06};
        i2c_.write(addr_, cmd, 2);

        // 2. 等待测量完成 (典型: ~15ms)
        delay_ms(15);

        // 3. 读取6字节数据
        uint8_t data[6];
        i2c_.read(addr_, data, 6);

        // 4. 解析温度值
        uint16_t rawTemp = (data[0] << 8) | data[1];
        float temperature = -45.0f + 175.0f * rawTemp / 65535.0f;

        return TemperatureData{
            .value = temperature,
            .timestamp_ms = getTickMs()
        };
    }

    // ... 其他接口实现
};
```

## 14. 风险与应对

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| **RTOS兼容性** | 中断安全/线程安全问题 | 中 | 提供线程安全和无锁两种模式；Bare-metal下禁用锁 |
| **不同MCU浮点性能差异** | 卡尔曼/FIR在无FPU的MCU上性能差 | 中 | 提供定点数实现版本；按FPU能力自动选择 |
| **内存碎片** | 动态分配导致堆碎片 | 中 | 优先使用静态分配（StaticVector/RingBuffer）；内存池 |
| **总线冲突** | I2C/SPI多设备共享冲突 | 低 | 总线加锁；资源所有权明确 |
| **实时性不足** | 滤波Pipeline过长导致延迟 | 低 | Pipeline长度限制；优先级配置；超时保护 |
| **C++编译器兼容性** | 各MCU编译器对C++17支持不同 | 中 | 避免使用最新特性；编译期兼容检测；提供降级策略 |
| **异常处理开销** | 异常监控本身消耗CPU和内存 | 低 | 异常检测与正常数据路径分离；低优先级后台任务执行非关键检测 |
| **测试维护成本** | Mock与真实硬件行为偏差导致假阳性/假阴性 | 中 | Mock行为定期与真实硬件校准；HIL测试作为最终验证门禁 |
| **Profile裁剪验证不足** | 某些Profile组合未测试，客户定制组合出现编译错误 | 中 | CI矩阵编译覆盖所有Profile组合；通过`nm`验证裁剪残留；定期发布兼容性报告 |
| **资源过度裁剪导致功能缺失** | Minimal Profile过于精简，实际产品需求无法满足 | 低 | 提供Standard Profile作为推荐基线；提供Profile升级迁移指南 |
| **8位平台编译器不兼容** | SDCC/XC8等不支持C++，IAR模板支持不完整 | 高 | 提供C胶水层(c_binding.h)；关键路径使用C-linkage函数；CI覆盖AVR/MSP430编译器构建 |
| **定点数精度不足** | Q15.16格式在多次乘积累积后误差累积 | 中 | 乘法后立即右移16位防溢出；关键路径保留双精度int64_t中间结果；提供精度对比测试套件 |
| **C++11特性缺失导致代码膨胀** | 不用if constexpr导致死分支无法编译期消除 | 低 | 死分支用#if/#ifdef预编译宏替代；依赖编译器-Os优化消除死代码 |

```cpp
// ─── Mock I2C总线（白盒测试核心依赖） ────────────────────
class MockI2CBus : public II2CBus {
public:
    // 预设设备行为：地址 → 返回数据队列
    void setDeviceResponse(uint8_t addr,
                           const std::vector<uint8_t>& response) {
        deviceResponses_[addr].push(response);
    }

    // 预设错误场景
    void setNackOnAddress(uint8_t addr) {
        nackAddresses_.insert(addr);
    }

    // 记录写入数据（供断言使用）
    std::vector<std::pair<uint8_t, std::vector<uint8_t>>> writeHistory;

    // --- II2CBus接口实现 ---
    bool write(uint8_t addr, const uint8_t* data, size_t len) override {
        if (nackAddresses_.count(addr)) return false;  // 模拟NACK
        writeHistory.push_back({addr, {data, data + len}});
        return true;
    }

    bool read(uint8_t addr, uint8_t* data, size_t len) override {
        if (nackAddresses_.count(addr)) return false;
        auto& queue = deviceResponses_[addr];
        if (queue.empty()) return false;
        auto& resp = queue.front();
        memcpy(data, resp.data(), std::min(len, resp.size()));
        queue.pop();
        return true;
    }

private:
    std::map<uint8_t, std::queue<std::vector<uint8_t>>> deviceResponses_;
    std::set<uint8_t> nackAddresses_;
};
```

```
                         │       异常事件 (Exception)      │
                         └──────────────┬───────────────┘
                                        │
              ┌─────────────────────────┼─────────────────────────┐
              │                         │                         │
              ▼                         ▼                         ▼
    ┌─────────────────┐    ┌─────────────────────┐    ┌─────────────────┐

    └────────┬────────┘    └──────────┬──────────┘    └────────┬────────┘
             │                        │                        │
    ┌────────┼────────┐       ┌───────┼────────┐       ┌───────┼────────┐
    ▼        ▼        ▼       ▼       ▼        ▼       ▼       ▼        ▼

  NACK   错误    无应答   量程范围  冻结   突变   不足   发散   栈溢出
  (CRC)  (DMA)   (噪声)  (OOB)  (Frozen)(Spike)(OOM)(Diverge)(Stack)
```

### 16.2 异常严重级别定义

| 级别 | 名称 | 判定条件 | 默认处理策略 | 恢复方式 |
|------|------|----------|-------------|----------|
| **L0** | 通知 | 偶发通信重试成功、轻微噪声波动 | 记录日志，不中断 | 自动 |
| **L1** | 警告 | 连续重试2-3次成功、数据接近边界 | 记录日志 + EventBus通知 | 自动 |
| **L2** | 错误 | 连续失败超阈值(如5次)、数据越界 | 降级(使用上次有效值) + 告警 | 半自动(需重试恢复) |
| **L3** | 致命 | 熔断触发、传感器彻底无响应、硬件损坏 | 停止采样 + 紧急告警 + 尝试复位 | 需人工/系统复位 |

### 16.3 核心接口设计

```cpp
// ─── 异常类型定义 ──────────────────────────────────────
enum class ExceptionCategory {
    COMMUNICATION,      // 通信异常
    DATA_VALIDITY,      // 数据有效性异常
    FILTER_ANOMALY,     // 滤波异常
    SYSTEM_RESOURCE,    // 系统资源异常
};

enum class ExceptionSeverity {
    INFO    = 0,        // L0: 通知
    WARNING = 1,        // L1: 警告
    ERROR   = 2,        // L2: 错误
    FATAL   = 3,        // L3: 致命
};

struct ExceptionEvent {
    uint32_t            timestamp_ms;
    uint32_t            sensor_id;
    ExceptionCategory   category;
    ExceptionSeverity   severity;
    uint16_t            error_code;        // 具体错误码
    float               context_value;     // 异常发生时的数据值
    uint32_t            consecutive_count; // 连续异常次数
};

// ─── 异常检测器接口 ────────────────────────────────────
class IExceptionDetector {
public:
    virtual ~IExceptionDetector() = default;

    // 检测输入数据/状态是否存在异常
    // 返回 true 表示检测到异常，同时填充 event
    virtual bool detect(const SensorData& data,
                        const SensorStatus& status,
                        ExceptionEvent& event) = 0;

    // 重置检测器状态
    virtual void reset() = 0;

    virtual const char* getName() const = 0;
};

// ─── 异常处理器接口 ────────────────────────────────────
enum class RecoveryAction {
    NONE,               // 无动作
    RETRY,              // 重试通信
    USE_LAST_VALID,     // 使用上次有效值（降级）
    USE_DEFAULT,        // 使用默认值（降级）
    RESET_SENSOR,       // 复位传感器
    STOP_SAMPLING,      // 停止采样
    SYSTEM_ALERT,       // 系统告警
};

struct RecoveryResult {
    RecoveryAction  action;
    bool            success;
    float           fallback_value;     // 降级时使用的值
};

class IExceptionHandler {
public:
    virtual ~IExceptionHandler() = default;

    // 根据异常事件返回处理策略
    virtual RecoveryResult handle(const ExceptionEvent& event) = 0;

    // 获取当前熔断状态
    virtual bool isCircuitOpen() const = 0;
};
```

### 16.4 具体异常检测器实现

#### 16.4.1 通信异常检测器

```cpp
class CommExceptionDetector : public IExceptionDetector {
public:
    CommExceptionDetector(uint32_t maxRetries = 3,
                          uint32_t retryIntervalMs = 100)
        : maxRetries_(maxRetries)
        , retryIntervalMs_(retryIntervalMs) {}

    bool detect(const SensorData& data, const SensorStatus& status,
                ExceptionEvent& event) override {
        // 检查通信失败标志
        if (status == SensorStatus::COMM_ERROR) {
            consecutiveErrors_++;

            event.category = ExceptionCategory::COMMUNICATION;
            event.severity = (consecutiveErrors_ >= maxRetries_)
                ? ExceptionSeverity::ERROR
                : ExceptionSeverity::WARNING;
            event.consecutive_count = consecutiveErrors_;
            event.error_code = ERR_I2C_NACK;  // 具体错误码
            return true;
        }

        // 正常通信 → 重置计数
        consecutiveErrors_ = 0;
        return false;
    }

    void reset() override { consecutiveErrors_ = 0; }

private:
    uint32_t maxRetries_;
    uint32_t retryIntervalMs_;
    uint32_t consecutiveErrors_ = 0;
};
```

#### 16.4.2 数据异常检测器

```cpp
class DataExceptionDetector : public IExceptionDetector {
public:
    DataExceptionDetector(float minValid, float maxValid,
                          float maxChangeRate,
                          uint32_t frozenThresholdMs)
        : minValid_(minValid), maxValid_(maxValid)
        , maxChangeRate_(maxChangeRate)
        , frozenThresholdMs_(frozenThresholdMs) {}

    bool detect(const SensorData& data, const SensorStatus& status,
                ExceptionEvent& event) override {
        // 1. 超出量程检测
        if (data.value < minValid_ || data.value > maxValid_) {
            event.category = ExceptionCategory::DATA_VALIDITY;
            event.severity = ExceptionSeverity::ERROR;
            event.error_code = ERR_OUT_OF_RANGE;
            event.context_value = data.value;
            return true;
        }

        // 2. 数据冻结检测（长时间不变）
        if (data.value == lastValue_) {
            if (data.timestamp_ms - lastChangeTime_ > frozenThresholdMs_) {
                event.category = ExceptionCategory::DATA_VALIDITY;
                event.severity = ExceptionSeverity::ERROR;
                event.error_code = ERR_DATA_FROZEN;
                event.context_value = data.value;
                return true;
            }
        } else {
            lastChangeTime_ = data.timestamp_ms;
        }

        // 3. 突变检测（相邻采样差值过大）
        float delta = std::abs(data.value - lastValue_);
        if (delta > maxChangeRate_ && lastValue_ != INVALID_FLOAT) {
            event.category = ExceptionCategory::DATA_VALIDITY;
            event.severity = ExceptionSeverity::WARNING;
            event.error_code = ERR_SPIKE_DETECTED;
            event.context_value = delta;
            lastValue_ = data.value;
            return true;
        }

        lastValue_ = data.value;
        return false;
    }

    void reset() override {
        lastValue_ = INVALID_FLOAT;
        lastChangeTime_ = 0;
    }

private:
    float minValid_, maxValid_, maxChangeRate_;
    uint32_t frozenThresholdMs_;
    float lastValue_ = INVALID_FLOAT;
    uint32_t lastChangeTime_ = 0;
};
```

#### 16.4.3 滤波异常检测器

```cpp
class FilterExceptionDetector : public IExceptionDetector {
public:
    bool detect(const SensorData& data, const SensorStatus& status,
                ExceptionEvent& event) override {
        float filtered = data.value;       // 滤波后值
        float raw = data.raw_value;        // 原始值

        // 1. NaN/Inf 检测
        if (std::isnan(filtered) || std::isinf(filtered)) {
            event.category = ExceptionCategory::FILTER_ANOMALY;
            event.severity = ExceptionSeverity::ERROR;
            event.error_code = ERR_FILTER_NAN;
            return true;
        }

        // 2. 滤波发散检测: 滤波后偏差持续增大
        float deviation = std::abs(filtered - raw);
        if (deviation > lastDeviation_ * 3.0f) {
            divergenceCount_++;
        } else {
            divergenceCount_ = 0;
        }
        lastDeviation_ = deviation;

        if (divergenceCount_ >= DIVERGENCE_THRESHOLD) {
            event.category = ExceptionCategory::FILTER_ANOMALY;
            event.severity = ExceptionSeverity::ERROR;
            event.error_code = ERR_FILTER_DIVERGENCE;
            return true;
        }

        return false;
    }

private:
    static constexpr uint32_t DIVERGENCE_THRESHOLD = 5;
    float lastDeviation_ = 0.0f;
    uint32_t divergenceCount_ = 0;
};
```

### 16.5 熔断保护机制 (Circuit Breaker)

```
                    正常状态             半开状态
                 ┌──────────┐       ┌──────────┐
    ┌───────────▶│  CLOSED  │──────▶│ HALF_OPEN│◀───┐
    │            │ (正常采样) │       │ (探测恢复) │    │
    │            └──────────┘       └─────┬────┘    │
    │                                     │         │
    │              连续失败               │ 探测成功  │ 探测失败
    │              超阈值                 │         │
    │                 │                  │         │
    │                 ▼                  ▼         │
    │            ┌──────────┐       ┌──────────┐    │
    └────────────│  OPEN    │──────▶│  CLOSED  │────┘
                 │ (停止采样) │ 冷却超时│ (正常采样) │
                 └──────────┘       └──────────┘
```

```cpp
class CircuitBreaker {
public:
    enum State { CLOSED, OPEN, HALF_OPEN };

    CircuitBreaker(uint32_t failureThreshold = 5,
                   uint32_t cooldownMs = 30000)
        : failureThreshold_(failureThreshold)
        , cooldownMs_(cooldownMs) {}

    // 记录一次操作结果
    void recordSuccess() {
        consecutiveFailures_ = 0;
        if (state_ == HALF_OPEN) {
            state_ = CLOSED;  // 探测成功 → 恢复正常
        }
    }

    void recordFailure() {
        consecutiveFailures_++;
        if (state_ == HALF_OPEN) {
            state_ = OPEN;    // 探测失败 → 重新断开
            openedAt_ = getCurrentTimeMs();
        } else if (consecutiveFailures_ >= failureThreshold_) {
            state_ = OPEN;    // 连续失败超阈值 → 熔断
            openedAt_ = getCurrentTimeMs();
        }
    }

    // 是否允许执行操作
    bool allowRequest() {
        if (state_ == CLOSED) return true;
        if (state_ == OPEN) {
            if (getCurrentTimeMs() - openedAt_ > cooldownMs_) {
                state_ = HALF_OPEN;  // 冷却结束 → 探测
                return true;
            }
            return false;  // 仍在冷却中
        }
        return true;  // HALF_OPEN: 允许探测请求
    }

    State getState() const { return state_; }
    uint32_t getConsecutiveFailures() const { return consecutiveFailures_; }

    void reset() {
        state_ = CLOSED;
        consecutiveFailures_ = 0;
    }

private:
    State state_ = CLOSED;
    uint32_t failureThreshold_;
    uint32_t cooldownMs_;
    uint32_t consecutiveFailures_ = 0;
    uint32_t openedAt_ = 0;
};
```

```cpp
// ─── 异常日志（环形缓冲区，内存安全） ───────────────────
class ExceptionLogger {
public:
    static constexpr size_t MAX_LOG_ENTRIES = 64;

    void log(const ExceptionEvent& event) {
        buffer_[writeIndex_ % MAX_LOG_ENTRIES] = event;
        writeIndex_++;
        totalCount_++;
    }

    // 按严重级别过滤查询
    std::vector<ExceptionEvent> getRecent(
        ExceptionSeverity minSeverity = ExceptionSeverity::WARNING,
        size_t maxCount = 10) const;

    const ExceptionEvent& last() const {
        return buffer_[(writeIndex_ - 1) % MAX_LOG_ENTRIES];
    }

    uint32_t totalExceptionCount() const { return totalCount_; }
    void clear() { writeIndex_ = 0; totalCount_ = 0; }

private:
    std::array<ExceptionEvent, MAX_LOG_ENTRIES> buffer_;
    size_t writeIndex_ = 0;
    uint32_t totalCount_ = 0;
};

// ─── 异常通知订阅者 ────────────────────────────────────
// 异常事件同样走EventBus，应用层可订阅异常Topic
class ExceptionEventBus {
public:
    void subscribe(ExceptionCategory category,
                   IExceptionSubscriber* sub);
    void unsubscribe(ExceptionCategory category,
                     IExceptionSubscriber* sub);
    void publish(const ExceptionEvent& event);

    // 预定义的异常订阅者：
    // · GuiAlertSubscriber   → GUI弹窗/状态栏告警图标
    // · MqttAlertSubscriber  → MQTT异常主题上报云端
    // · SafetySubscriber     → 安全联动（如加热器关闭）
};

// ─── 使用示例：传感器集成异常处理 ────────────────────────
class SafeSensorWrapper {
public:
    SafeSensorWrapper(std::unique_ptr<SensorBase<TemperatureData>> sensor,
                      ExceptionEventBus& exBus)
        : sensor_(std::move(sensor)), exBus_(exBus) {}

    TemperatureData safeRead() {
        // 1. 熔断检查
        if (!breaker_.allowRequest()) {
            return lastValidData_;  // 返回缓存的有效数据
        }

        // 2. 尝试读取
        auto data = sensor_->readRaw();

        // 3. 逐一检测异常
        ExceptionEvent event{};
        for (auto& detector : detectors_) {
            if (detector->detect(data, sensor_->getStatus(), event)) {
                // 记录失败
                breaker_.recordFailure();

                // 获取处理策略
                auto recovery = handler_->handle(event);

                // 记录日志并分发异常事件
                logger_.log(event);
                exBus_.publish(event);

                // 执行恢复动作
                return executeRecovery(recovery, data);
            }
        }

        // 4. 一切正常
        breaker_.recordSuccess();
        lastValidData_ = data;
        return data;
    }

private:
    std::unique_ptr<SensorBase<TemperatureData>> sensor_;
    ExceptionEventBus& exBus_;
    CircuitBreaker breaker_;
    ExceptionLogger logger_;
    std::vector<std::unique_ptr<IExceptionDetector>> detectors_;
    std::unique_ptr<IExceptionHandler> handler_;
    TemperatureData lastValidData_;
};
```

## 18. 8位/16位MCU适配与定点数方案

### 18.1 设计动机

> **评审意见R005**：MCU平台支持需扩展到8位和16位单片机（AVR、MSP430、STM8、PIC等），可接受功能大幅裁剪。

8位和16位MCU在成本敏感型IoT终端（传感器节点、一次性温度记录仪、冷链标签）中大量使用。其核心约束：

| 约束 | 典型值 | 影响 |
|------|--------|------|
| **无硬件FPU** | 无浮点运算单元 | float运算被编译为软浮点库，单次加法~500周期 |
| **RAM极小** | 256B ~ 2KB | 滑动窗口大小严格受限，动态分配不可用 |
| **Flash有限** | 4KB ~ 32KB | 代码体积高度敏感，必须极致裁剪 |
| **栈空间小** | 64B ~ 256B | 递归禁止，函数调用深度需控制 |
| **编译器受限** | C++11子集 | IAR/SDCC/XC8对C++模板/异常支持不完整 |

### 18.2 定点数滤波数学库

定点数（Fixed-Point Q-format）用整数模拟小数，避免浮点软库开销。

**Q15.16格式（32-bit有符号整数，低16位为小数部分）**：

```
Q15.16 编码: value_int32 = round(real_value × 2^16)
范围: [-32768.0, 32767.99998]
精度: 1/65536 ≈ 0.000015
```

```cpp
// ─── q_math.hpp (C++11 兼容) ───────────────────────────
#pragma once
#include <cstdint>
#include "feature_config.hpp"

#if SENSOR_FEATURE_FIXED_POINT_MATH

// ★ 使用 typedef 而非 using（C++11兼容，且更明确）
typedef int32_t q15_16_t;
typedef int16_t q7_8_t;

namespace qmath {

// ─── 常量 ───────────────────────────────────────────────
const q15_16_t Q15_16_ONE  = 65536;    // 1.0
const q15_16_t Q15_16_HALF = 32768;    // 0.5
const q15_16_t Q15_16_ZERO = 0;

// ─── 转换 ───────────────────────────────────────────────
inline q15_16_t fromFloat(float v) {
    return static_cast<q15_16_t>(v * 65536.0f + (v >= 0 ? 0.5f : -0.5f));
}
inline float toFloat(q15_16_t v) {
    return static_cast<float>(v) / 65536.0f;
}

// ─── 基本运算（避免溢出） ────────────────────────────────
inline q15_16_t add(q15_16_t a, q15_16_t b) {
    return a + b;  // 依赖 int32_t 溢出回绕，结果直接为 Q15.16
}
inline q15_16_t sub(q15_16_t a, q15_16_t b) {
    return a - b;
}
inline q15_16_t mul(q15_16_t a, q15_16_t b) {
    // (a * b) >> 16，用 int64_t 防溢出
    return static_cast<q15_16_t>(
        (static_cast<int64_t>(a) * static_cast<int64_t>(b)) >> 16
    );
}
inline q15_16_t div(q15_16_t a, q15_16_t b) {
    // (a << 16) / b
    return static_cast<q15_16_t>(
        (static_cast<int64_t>(a) << 16) / static_cast<int64_t>(b)
    );
}

// ─── 定点数均值（窗口内求和后除法） ──────────────────────
inline q15_16_t mean(const q15_16_t* data, uint8_t count) {
    int32_t sum = 0;
    for (uint8_t i = 0; i < count; ++i) {
        sum += data[i];
    }
    // 用整数除法：(sum / count) 直接就是 Q15.16 格式的均值
    return sum / static_cast<int32_t>(count);
}

// ─── 定点数中值 ─────────────────────────────────────────
inline q15_16_t median(q15_16_t* sorted, uint8_t count) {
    // 冒泡排序（小窗口N≤7时比通用排序更快，且无递归）
    for (uint8_t i = 0; i < count - 1; ++i) {
        for (uint8_t j = 0; j < count - 1 - i; ++j) {
            if (sorted[j] > sorted[j + 1]) {
                q15_16_t tmp = sorted[j];
                sorted[j] = sorted[j + 1];
                sorted[j + 1] = tmp;
            }
        }
    }
    uint8_t mid = count / 2;
    if (count % 2 == 1) {
        return sorted[mid];
    } else {
        return (sorted[mid - 1] + sorted[mid]) / 2;
    }
}

} // namespace qmath

// ─── C++11 操作符重载（无 constexpr，无 noexcept） ───────
class Q15_16 {
public:
    Q15_16() : v_(0) {}
    explicit Q15_16(q15_16_t raw) : v_(raw) {}
    explicit Q15_16(float f) : v_(qmath::fromFloat(f)) {}

    float toFloat() const { return qmath::toFloat(v_); }
    q15_16_t raw() const { return v_; }

    Q15_16 operator+(Q15_16 other) const {
        return Q15_16(v_ + other.v_);
    }
    Q15_16 operator-(Q15_16 other) const {
        return Q15_16(v_ - other.v_);
    }
    Q15_16 operator*(Q15_16 other) const {
        return Q15_16(qmath::mul(v_, other.v_));
    }
    Q15_16 operator/(Q15_16 other) const {
        return Q15_16(qmath::div(v_, other.v_));
    }
    bool operator<(Q15_16 other) const { return v_ < other.v_; }
    bool operator>(Q15_16 other) const { return v_ > other.v_; }

private:
    q15_16_t v_;
};

#endif // SENSOR_FEATURE_FIXED_POINT_MATH
```

### 18.3 定点数滤波器实现

```cpp
// ─── fixed_mean_filter.hpp (C++11兼容) ─────────────────
#pragma once
#include "feature_config.hpp"

#if SENSOR_FEATURE_FILTER_MEAN && SENSOR_FEATURE_FIXED_POINT_MATH

template <uint8_t N>
class FixedMeanFilter {
public:
    FixedMeanFilter() : writeIdx_(0) { reset(); }

    // 输入浮点值（传感器驱动接口保持浮点一致），内部转定点计算
    float update(float input) {
        buffer_[writeIdx_ % N] = qmath::fromFloat(input);
        writeIdx_++;
        if (writeIdx_ < N) {
            return input;  // 窗口未满透传
        }
        // 定点数均值
        return qmath::toFloat(qmath::mean(buffer_, N));
    }

    void reset() {
        writeIdx_ = 0;
        for (uint8_t i = 0; i < N; ++i) buffer_[i] = 0;
    }

private:
    q15_16_t  buffer_[N];   // 定点数窗口
    uint8_t   writeIdx_;    // 8位MCU上用uint8_t节省1字节
};

#endif
```

### 18.5 8位/16位编译器适配

| 编译器 | 目标MCU | C++标准 | 注意事项 |
|--------|---------|---------|----------|
| **AVR-GCC 5.4+** | ATmega/ATtiny | C++11 基本完整 | 不支持异常(用-fno-exceptions)；模板递归深度限制；`new`/`delete`需谨慎 |
| **MSP430-GCC 6+** | MSP430 | C++11 | 16位int，注意类型溢出；大内存模型用20-bit指针 |
| **IAR EWAVR** | AVR | C++11 子集 | 部分STL不支持；模板实例化深度需手动调大 |
| **IAR EW430** | MSP430 | C++11 子集 | 同上 |
| **SDCC** | STM8/8051 | C99为主，C++支持有限 | **不建议使用C++，降级为C接口封装** |
| **XC8** | PIC16/PIC18 | C99（无C++支持） | **降级为C接口封装**，框架提供C binding层 |
| **XC16** | PIC24/dsPIC | C++11 子集 | 基本可用，std::命名空间不完整 |

```cpp
// ─── c_binding.h: 为SDCC/XC8提供C语言胶水层 ────────────
#ifdef __cplusplus
extern "C" {
#endif

// 不透明指针：C代码不感知C++对象布局
typedef void* sensor_handle_t;

sensor_handle_t sensor_create(uint8_t sensor_type, uint8_t bus_id);
float           sensor_read_raw(sensor_handle_t handle);
float           sensor_read_filtered(sensor_handle_t handle);
void            sensor_destroy(sensor_handle_t handle);

#ifdef __cplusplus
}
#endif
```

### 18.6 8位平台特化设计原则

| 原则 | 说明 |
|------|------|
| **模板参数用uint8_t** | 窗口大小、滤波器数量等常量用`uint8_t`代替`size_t`，节省1-2字节 |
| **禁止动态内存** | 所有buffer编译期确定大小；`static_vector`取代`std::vector` |
| **内联优先** | 小函数无条件inline，避免函数调用压栈开销 |
| **递归禁止** | 排序用冒泡/插入排序（小N），不使用快排递归 |
| **整数运算优先** | 启用定点数时全部计算走整数路径；浮点仅用于对外接口转换 |
| **编译期常量** | 窗口大小、滤波系数等全部模板参数化，编译期确定消除分支 |

## 附录C: C++11兼容性约束与降级策略

> **评审意见R006**：C++最低标准从C++17降低至C++11。

### C.1 框架中使用的C++14/17特性替代方案

| C++14/17特性 | 用途 | C++11替代方案 |
|-------------|------|--------------|
| `std::make_unique<T>(args...)` | 智能指针创建 | `std::unique_ptr<T>(new T(args...))` |
| `if constexpr(cond)` | 编译期分支 | `#if` / `#ifdef` 预编译宏 或 SFINAE模板特化 |
| `std::optional<T>` | 可选返回值 | `bool tryGet(T& out)` 模式 或 `T*` (nullptr表示无值) |
| Structured bindings `auto [a,b] = ...` | 多返回值解包 | 显式 `std::pair` / `std::tuple` + `std::get<N>()` |
| `constexpr` 函数宽松化 | 编译期计算 | `#define` 宏常量 或 模板元编程 |
| `std::string_view` | 零拷贝字符串 | `const char*` + `size_t` 或 `const std::string&` |
| `[[nodiscard]]` | 返回值不可忽略 | 编译器扩展 `__attribute__((warn_unused_result))` (GCC/Clang) |
| `auto` 返回类型推导 | 简化模板返回 | 显式 `-> decltype(...)` 尾置返回类型 |
| `std::array<T,N>` 的 `constexpr` 方法 | — | 使用C风格数组 `T[N]` |
| `std::isnan` / `std::isinf` | 浮点判断 | `<cmath>` 中 `isnan()` / `isinf()` (C99宏) |

### C.4 各编译器已知限制与workaround

| 编译器 | 限制 | Workaround |
|--------|------|------------|
| AVR-GCC < 7 | `std::function` 不可用（依赖异常） | 使用函数指针 + `void*` context |
| MSP430-GCC | 大内存模型下虚函数表可能跨bank | 用 `__attribute__((section(".rodata")))` 固定vtable位置 |
| IAR EWAVR | 模板深度默认64，复杂Pipeline易超 | 编译选项 `--template_depth 128` |
| XC8 | 完全不支持C++ | 框架提供纯C胶水层 `c_binding.h` |
| SDCC | C++支持极有限 | 降级为C接口 |

## 附录A: 关键技术选型对比

### A.1 C++ vs C 实现对比

| 维度 | C++ | C |
|------|-----|---|
| 接口抽象 | 虚基类/模板，类型安全 | 函数指针+void*，易出错 |
| 代码复用 | 继承/组合/模板 | 宏+函数指针 |
| 编译期优化 | 模板/constexpr零开销 | 宏展开 |
| RAM占用 | 虚表开销(vptr 4-8B) | 手动实现更省 |
| 学习曲线 | 较高 | 较低 |
| **选择** | ✅ **推荐**（功能需求复杂，抽象收益高） | 备选（极简资源场景） |

### A.2 发布-订阅 vs 回调函数对比

| 维度 | 发布-订阅 | 直接回调 |
|------|-----------|----------|
| 一对多分发 | ✅ 原生支持 | 需手动维护回调链 |
| 解耦程度 | ✅ 高（发布者不知道订阅者） | 低（传感器持有回调列表） |
| 灵活性 | ✅ 动态订阅/取消 | 一般 |
| 开销 | 略高（事件总线查找） | 低（直接调用） |
| **选择** | ✅ **推荐**（解耦是核心需求） | — |
